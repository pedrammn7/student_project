# Student Project

## Description
A beginner-friendly Python project for learning Git, GitHub and branching step by step.
It contains two small scripts:
- `main.py` prints welcome messages for the Python course.
- `student.py` prints a student's name and grade, and the class average.

## How to Run
Requirements: Python 3.8 or newer.
```bash
git clone https://github.com/pedrammn7/student_project.git
cd student_project
python main.py
python student.py
```

## Git Concepts Used
- `git init`, `git status`, `git add`, `git commit`, `git log`, `git diff`
- `git commit --amend` to fix the last commit
- Branches (`feature`, `bugfix`, `feature/student-info`) and `git merge`
- `git stash` / `git stash pop` to put work aside
- `git revert` (safe undo, keeps history) vs `git reset` (moves the branch, rewrites history)
- Resolving a merge conflict in `README.md`
- Remote repository on GitHub: `git remote`, `git push -u`, `git clone`, `git pull`
- Authentication with a Personal Access Token (HTTPS) and SSH keys
